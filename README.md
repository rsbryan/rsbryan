# Steven Bryan

Senior CS major at San Diego State, graduating May 2027. I build software
that has to be right about numbers.

**The Lifting App** is a strength training log for iOS with an AI coach
that reads your sets before it answers, cites the exact lifts it used,
and writes training programs through validated tool calls with its
mistakes fed back to the model. React Native and Expo, Postgres with row
level security, Swift Live Activities and widgets, Claude with streaming
tool use. Launching on the App Store in October 2026.
[theliftingapp.com](https://www.theliftingapp.com) ·
[what's inside](https://github.com/rsbryan/the-lifting-app)

**Vitals** is a single-user health analytics app that reads Apple Watch
data live, syncs it to Postgres, and shows the same dashboard on iOS and
web from one Expo codebase.

Before this I was a software engineer intern at Browserbase, where I
built the evaluation infrastructure for Google's computer use model
launch and ran the benchmarks against OpenAI and Anthropic that went into
the launch materials. Some of that is in Stagehand v3, which is open
source.

Training for Ironman 70.3 Oceanside. The two apps above exist because I
