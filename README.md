# Steven Bryan

Senior CS major at San Diego State, graduating May 2027

**The Lifting App** is a strength training log for iOS with an AI coach
that reads your sets before it answers, cites the exact lifts it used,
and writes training programs through validated tool calls with its
mistakes fed back to the model. React Native and Expo, Postgres with row
level security, Swift Live Activities and widgets, Claude with streaming
tool use. Launching on the App Store in October 2026.
